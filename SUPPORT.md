# Getting Support for LongGuard

Thank you for using **LongGuard**! Here is how to find help, report issues, and connect with the community.

---

## 1. Documentation & Guides

Before opening an issue, check the official documentation:

- **Official Documentation**: https://endevsols.github.io/LongGuard/
- **Quick Start**: https://endevsols.github.io/LongGuard/getting-started/
- **Integrations**:
  - [LangGraph Integration](https://endevsols.github.io/LongGuard/integrations/langgraph/)
  - [LangChain Integration](https://endevsols.github.io/LongGuard/integrations/langchain/)
  - [CrewAI Integration](https://endevsols.github.io/LongGuard/integrations/crewai/)
  - [Raw Client (OpenAI / Anthropic)](https://endevsols.github.io/LongGuard/integrations/raw-client/)
- **Concepts & Detectors**: https://endevsols.github.io/LongGuard/concepts/detectors/

---

## 2. Questions & Usage Discussions

For general questions, architecture discussions, or sharing your agent setup:

- **GitHub Discussions**: https://github.com/ENDEVSOLS/LongGuard/discussions
- **GitHub Issues**: Please reserve issues for reproducible bugs and targeted feature requests.

---

## 3. Reporting Bugs

If you encounter unexpected behavior or a bug:

1. Search existing [GitHub Issues](https://github.com/ENDEVSOLS/LongGuard/issues) to avoid duplicates.
2. Open a new issue using our **Bug Report** template.
3. Include:
   - LongGuard, Python, and OS versions
   - Framework versions (`langgraph`, `langchain`, `crewai`, etc.)
   - Minimal reproduction code snippet
   - Redacted `GuardReport` output or logs if applicable

---

## 4. Security Vulnerabilities

Please **do not** open public GitHub issues for security vulnerabilities.
Refer to our [Security Policy](SECURITY.md) or email **technology@endevsols.com**.
