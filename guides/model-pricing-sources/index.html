    Model pricing source audit

    Verified on 2026-10-09 against official provider documentation. Prices below are USD per million tokens, written as input / output. The Python registry stores these amounts divided by 1,000,000. This is a standard, uncached text API snapshot, not a live availability check or a guarantee of access for an account.

    The supported-price tables below match the project's selected built-in registry in src/longguard/pricing.py. A model can be excluded by project selection even while its provider still offers it. The decision tables distinguish those exclusions from retirement or unverifiable pricing. Use list_supported_models() for the current supported IDs and explicit per-token overrides for excluded models.

    Estimation limits

    The current ModelPricing interface has only input/output prices. It cannot represent long-context tiers, cache hits/writes, region or service-tier multipliers, modality rates, server-tool charges, or contract pricing. Built-in entries therefore estimate ordinary uncached text usage at the base tier. Supply explicit per-token overrides for other billing arrangements. Account permissions and provider lifecycle changes can affect whether an API call works.
