# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability within LongGuard, please do **not** open a public issue on GitHub.

Instead, report it responsibly by emailing:

**security@endevsols.com** or **info@endevsols.com**

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept script.
- Any suggested mitigations or patches.

We will acknowledge receipt of your vulnerability report within 48 hours and coordinate a patch and responsible disclosure timeline.
